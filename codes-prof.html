Code d'un point de contrôle

Un élève est bloqué sur un écran « Point de contrôle ». Vérifie son bilan, puis génère son code.

Les accents, les majuscules et les espaces ne comptent pas : « Léa » et « lea » donnent le même code.

Vérifier un code de réussite

L'élève a recopié son code de réussite sur sa feuille. Tape son prénom et son code : la page retrouve le jeu, le niveau et le score réel.
